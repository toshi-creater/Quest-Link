## デザイン特徴

### 配色

| 役割         | 色                |
| ---------- | ---------------- |
| Primary    | 紫 (#7C3AED)      |
| Secondary  | シアン (#06B6D4)    |
| Accent     | ライム (#84CC16)    |
| Background | ダークグレー (#111827) |


### タイポグラフィ
- 見出し・ブランド名: `Orbitron`（Google Fonts）— ゲーミング感のある幾何学的フォント
- 本文・UI: `DM Sans` または `Nunito`
- 数値表示: モノスペース系で揃える

### アニメーション
- ページロード時: 要素が下からフェードイン（staggered、100msずつ遅延）
- ボタン・カードホバー: スケールアップ + glow エフェクト
- アクティブなタブやナビ: accent-purple の縦または横バーでハイライト

### ボタンスタイル
- **プライマリCTAボタン**: accent-purple 背景、白テキスト、角丸、ホバーで明るく光る
- **セカンダリ / フィルターボタン**: ピル型、半透明背景、薄いボーダー

### レスポンシブデザイン
- ヘッダーはデスクトップ画面では上に固定。
- スマホの場合は下に固定でアイコンのみ。

## デザインチェックポイント

### ユーザビリティ

* 主要な機能に3タップ以内でアクセスできるか
* ボタンやタップ領域は十分な大きさか
* フォームの入力項目は最小限に抑えられているか
* エラーメッセージは具体的で、解決方法を示しているか

### チェックポイント

* すべての画面で同じデザインシステムを使用しているか
* ナビゲーションの位置や挙動は統一されているか
* 色の使い方にルールがあるか（例：青=リンク、赤=エラー）
* 似た機能には似たデザインパターンを使っているか

### アクセシビリティ 

* テキストと背景のコントラスト比は4.5:1以上か
* 色だけで情報を伝えていないか（色覚多様性への配慮）
* フォントサイズは調整可能か
* スクリーンリーダーに対応しているか
